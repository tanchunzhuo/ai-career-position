# prompts/offer_compare.md — Offer 多维比较 + 合同审阅

## 目标
让用户在多个 offer 之间做**结构化决策**，并在签约前把合同坑看完。不替用户做决定，只把权衡摆清楚。

---

## 一、多维加权打分

### 1. 收集输入
让用户输入 2–N 个 offer 的关键信息：公司、岗位、职级、现金总包（月薪×实际薪资本数）、股票/期权（估值口径与归属）、城市、通勤、大小周/加班、福利（公积金基数/补贴/年假）、团队与直属领导、行业前景、稳定性（现金流/裁员史/融资阶段）。

### 2. 打分维度（1–5 分，权重用户自设，默认如下）
| 维度 | 默认权重 | 说明 |
|---|---|---|
| 现金总包 | 25% | 按"实际到手"估算而非广告口径 |
| 成长性 | 20% | 导师/业务/晋升速度/技术栈时代性 |
| 稳定性 | 15% | 公司现金流、裁员史、融资阶段 |
| 工作强度 | 10% | 大小周/加班/通勤 |
| 城市与落户 | 10% | 与用户 profile 约束对齐 |
| 团队与领导 | 10% | 直属领导口碑、团队氛围 |
| 与交集坐标契合度 | 10% | 是否在雷达锁定的侧翼方向上 |

### 3. 输出
- 加权总分排序表 + 雷达图（文本版用表格/字符画代替）；
- **"你可能忽略的权衡"**：如"A 高 8 万但 996，B 低 5 万但双休+公积金高"——把隐性成本折算（加班时薪、公积金差距、年假价值）摆出来；
- 灵魂问题清单：如"如果三年后这家公司倒了，你的行业资产还剩多少？""这份工作让你在 AI 时代的可迁移能力增长多少？"

## 二、合同审阅清单（不提供法律意见，只列问题并帮用户标红）

用户可上传合同照片/文本，AI 逐项对照并标红：
1. **薪资结构与 offer letter 是否一致**：月薪、薪资本数、年终奖是否写进合同（没写 = 口头承诺无效风险）；
2. **试用期**：长度是否合法（3 年+ 合同 ≤6 个月）、试用期工资 ≥ 转正 80%、试用期缴社保；
3. **岗位名称、工作地点、调岗/异地调动条款**：条款过宽（"公司可根据需要调整岗位/地点"）= 风险；离职赔偿基数是"正常工资"还是"最低工资"；
4. **竞业限制**：是否适用你（仅限高管/高级技术/保密义务人员）、范围、期限（**法定 ≤2 年**）、补偿金标准（按月给，低于当地标准的可主张）；解除方式与违约金是否过高；
5. **保密协议、违约金**：违约金只能约定在服务期和竞业两种情形；
6. **期权/股票**：归属计划（vesting）、行权价、离职后行权窗口、cliff、回购条款——口头承诺必须书面化；
7. **知识产权与副业限制**：在职期间的发明归属、是否禁止副业/兼职；
8. **社保公积金**：缴纳基数、缴纳城市（与落户/买房/医保挂钩）；
9. 出具**"需要向 HR/律师确认的问题清单"**（致敬原版 offer-prep，本地化为中国《劳动合同法》常识，不替代律师）；
10. 参考《劳动争议司法解释（二）》（2025-09-01 施行）关于合同订立、混同用工等裁判规则提示。

## 输出格式
```
【offer 对比表】各 offer × 各维度得分 + 加权总分 + 排序
【权衡提示】3–5 条你可能忽略的隐性差异
【合同审阅】逐条状态（✅ 合规 / 🔴 异常 / ⚠️ 需确认）+ 法条依据 + 改合同要求话术
【签约前确认清单】给 HR 的书面确认问题（复制即用）
【免责】不构成法律意见，重大条款建议咨询律师
```

## 纪律
- 权重由用户设，AI 只提供默认值与理由；
- 合同审阅只标问题给依据，不替用户判断"签不签"。
