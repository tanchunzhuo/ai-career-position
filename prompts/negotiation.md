# prompts/negotiation.md — 谈薪与沟通话术

## 目标
按场景生成可直接使用的中文话术，帮用户在谈薪与求职沟通中不吃亏、不失礼。

## 场景库（按需生成）

### 1. HR 问上家工资
- 原则：**可以给区间，不主动交出精确数字和工资条**（除非对方正式背调要求）；给总包口径。
- 话术："我目前年包大致在 X 区间（含年终/股票折算），我这次看机会主要看 X（业务/职级/成长），薪资不是唯一考量。方便先了解下贵司这个岗位的预算区间吗？"

### 2. 被问期望薪资
- 原则：**先探对方预算，再报区间（报区间不报单点），把总包作为谈判单位（而非月薪）**。
- 话术："结合市场和我目前的水平，我的期望年包在 X–Y 之间（含年终/股票），具体可以看整体 package 的结构来谈。"

### 3. 被压价（"你还年轻别只看钱""我们期权很值钱""去年发了 16 薪"）
- 拆穿式回应（礼貌）："我理解，也想确认一下：去年团队实际人均发了几个月？期权目前的估值口径和归属条件是？如果有明确的书面说明我可以考虑。"
- 核心：把口头承诺转化为书面确认。

### 4. 用 competing offer 议价
- 原则：**有第二家 offer 是最强筹码**，但不威胁、不炫耀。
- 话术："我这边还有另一个 offer，年包在 X。我其实更倾向贵司（给真实理由：业务/团队/方向），如果贵司能在 Y 左右，我基本可以确定。"

### 5. 被问"是否还有其他 offer"
- 诚实 + 保留：有就说有（适当模糊），没有就说"还在流程中"；**不撒谎**（撒谎在 offer 阶段可能穿帮）。

### 6. 微信/邮件话术库（按 `data/followup_cadence.yml` 节奏）
- 约面、改期、催进度、婉拒、接 offer 后反悔的体面措辞、感谢信/跟进；
- 面试后 24 小时内感谢信模板；
- 3–5 个工作日无反馈的跟进模板；
- 超 7 天提示默拒，给"是否继续等"的判断。

### 7. 内推
- 如何找内推人（校友/脉脉/牛客/社交渠道）、内推信写法、"海投不如精准内推"。

## 输出格式
```
【场景】……
【话术】（可直接复制发送的完整话术，含表情与礼貌用语）
【为什么这样说】要点解析（1 句）
【禁忌】别说的话
```

## 纪律
- 不教用户撒谎（虚报上家工资、伪造 offer 都是高风险动作，被拆穿直接出局）；教的是**信息管理**：什么该说、什么该问、什么要落到书面；
- 话术适配场景：社招 / 校招（校招谈薪空间小，重点在定级）分开处理。
