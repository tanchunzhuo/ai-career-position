# prompts/story_bank.md — 面试故事银行

## 目标
引导用户沉淀 **5–8 个 STAR+R 万能故事**（每个：情境、任务、行动、结果、反思），存 `workspace/interviews/stories/*.md`，跨多次评估累积复用。

## 采集问题模板（对话式，逐个问）
1. 你职业生涯中最拿得出手的一件事是什么？（结果导向）
2. 一次你力挽狂澜/解决棘手问题的经历？（难题导向）
3. 一次失败/搞砸的经历，你从中学到了什么？（反思导向，考察成长性）
4. 一次跨部门/说服他人的经历？（协作/影响力）
5. 一次高压/短时限下完成的经历？（抗压）
6. 一次你主动改变流程/推动改进的经历？（主动性）

## 每个故事的结构（STAR+R）
```
## 故事名：[一句话概括，如"数据报表自动化"]

- 标签：[领导力/冲突/失败/抗压/数据驱动/跨部门/技术难点/主动性…]
- S 情境：背景、任务目标（2 句话，含可量化背景）
- T 任务：你具体负责什么、责任边界
- A 行动：你做了什么（分 3 步，强调你的判断与取舍，不用"我们"）
- R 结果：量化结果（数字/时间/比例），如"效率 +40%、出错率 -70%"
- R 反思：你学到什么、如果再遇到会怎样
- 可回答的问题：[面试官可能怎么问，预埋追问]
```

## 匹配规则
- 评估新 JD 或准备面试时，读岗位常见问题（`data/interview_formats.yml`）+ 故事标签，自动匹配；
- 输出"这 3 个故事可回答这 5 个问题"映射表；
- 一个故事准备 1 分钟版 + 3 分钟版。

## 纪律
- **严守真实**：只记录用户真实经历，AI 帮助润色表达（结构、量化、动词），**不杜撰**；
- 追问核实数字：用户说"提升很多"要追问"具体多少"，数字不实就让用户确认；
- 每个故事配"追问预案"：面试官深挖时的 3 个可能追问 + 应答要点。
