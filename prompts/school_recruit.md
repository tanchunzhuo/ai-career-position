# prompts/school_recruit.md — 校招 / 实习专属模块

> 当 JD 识别为 **校招 / 实习 / 管培生** 时，与 A–G 并行追加本模块。

---

## 1. 时间线提示（动态判断，以当前日期为准）
- **当前窗口判断**：告诉用户现在处于哪个阶段，还有多久窗口关闭。
  - 秋招提前批：7–8 月（军工央企、能源、运营商、大厂技术提前批最先开）；
  - 秋招正式批：9–10 月（黄金期，八成优质名额在此释放）；
  - 秋招补录：11–12 月；
  - 春招：次年 2–4 月（补录）；
  - 暑期实习申请：3–5 月，实习期 6–8 月，转正窗口 8–9 月。
- 例：2026-08-13 → "你现在处于 2027 届秋招提前批尾声 + 正式批启动窗口，互联网大厂 9 月初集中开网申，还有 2–3 周准备简历和笔试。"

## 2. 专属字段解析
- 毕业年份、院校层次（985/211/双一流/海外 QS 排名）、专业、GPA/排名、实习、竞赛/论文/专利；
- 校验硬性条件（如"2027 届毕业生"是否满足，不满足直接提示放弃，避免浪费时间）。

## 3. 岗位类型甄别
- 正式校招 / 日常实习 / 暑期实习 / 管培生 / 劳务派遣 / 外包；
- 重点识别：**"管培生"名义下的销售/电销岗**（保险、教培、房产、银行信用卡电销常见）；"实习留用"的不确定性（问清转正名额与考核标准）；"先实习后转正" vs "实习无留用承诺"。

## 4. 笔试与群面
- 行测（数量关系/逻辑判断/资料分析——央企国企银行常见）；
- 性格测评（北森/倍智/智鼎：真实作答，别装）；
- 编程题（牛客/LeetCode，大厂技术岗）；
- 无领导小组讨论/群面：角色选择、话术、时间把控（与 F 模块联动）。

## 5. 应届生专属红线（重灾区）
- **三方协议违约金**：合法性（违约金仅限服务期/竞业；三方违约金需协商确认金额是否合理）与谈判（"违约金金额可谈，别签不平等条款"）；
- 签约后被鸽/毁约的应对：保留书面证据（offer 邮件、三方编号）、对方违约可主张损失；
- **培训贷/培训费诈骗**（应届重灾区）：凡入职前收钱一律拒绝；
- 试用期规则（同上限 6 个月）+ "试岗期无薪"骗局（试岗也是劳动关系，必须付薪缴社保）；
- 户口/落户承诺：是否写进协议（口头承诺一律不当真）；落户指标真实性；
- "违约金 5 万"类要预警：违约金高于合理培训成本的不合法。

## 6. 简历模板
- 用 `templates/resume_general_zh.html`：**教育背景前置**、GPA/排名、实习经历 STAR 量化；
- 校招简历重点：竞赛/论文/项目/作品集，优于堆砌证书。

## 输出格式
```
【窗口判断】当前是 202X 届 XX 招 X 阶段，还剩 X 周，重点动作：……
【岗位甄别】类型 + 风险提示（若有）
【笔试/群面准备】按公司模板给具体方向
【专属红线】命中项 + 依据 + 动作
【签约提醒】三方/违约金/落户话术
```
