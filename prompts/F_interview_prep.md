# prompts/F_interview_prep.md — Block F 面试准备

## 目标
针对"这个岗位"生成可执行面试准备包：故事、问题预测、反问清单、备考计划。

## 步骤
1. **STAR+R 故事匹配**：
   - 读取 `workspace/interviews/stories/`（用 `scripts/story_bank.py` 或直接读 .md）；
   - 根据岗位常见问题（查 `data/interview_formats.yml`）匹配已有故事；
   - 缺的故事提示用户补充（给采集问题模板）；
   - 输出"这 3 个故事可回答这 5 个问题"的映射表；
2. **面试形式预判**（查 `data/interview_formats.yml`，按公司×岗位）：
   - HR 面：动机、稳定性、薪资预期、到岗时间；
   - 专业/业务面：项目深挖、coding/案例分析；
   - 总监/交叉/高管面、价值观面（如阿里"闻味官"、字节 context not control、华为狼性/奋斗者）；
   - **笔试**：行测、北森/倍智性格测评（提示"装好员工"会被识破，给真实作答建议）、编程题（牛客/LeetCode 方向）；
   - **无领导小组讨论/群面**（校招常见）：角色与话术提示（时间官/记录者/领导者/点子王，选适合自己的，别硬抢）；
3. **10 个高信息反问**（按岗位裁剪），并标注哪些问题**别在 HR 面问**（如"团队离职率"适合业务面问 HR 面问会尴尬）；
4. **备考计划**：按"距面试天数"排时间块（第 1–3 天：技术/业务深挖；第 4–5 天：模拟；第 6 天：HR/反问/着装与设备）；
5. **面试后引导 debrief**：问用户面完反馈，按模板沉淀复盘（什么题没答好、哪段经历被追问最多、下次改进）——借鉴原版 post-interview debrief，写回 `workspace/interviews/`。

## 输出格式
```
【故事映射】问题 → 故事（故事名/标签/要点），缺哪些故事
【形式预判】按公司模板：轮次、每轮时长、考察点、通过率感知
【高频题 Top 10】（该岗位特有 + 通用），每题给 1 分钟回答框架
【10 个高信息反问】按"业务面 5 个 / 主管面 3 个 / HR 面 2 个"分组，标注时机
【备考计划】按天排
【面试后复盘模板】面完回来填
```

## 纪律
- 只基于用户**真实经历**准备故事；不帮用户编造面试答案；
- 性格测评给"真实作答"建议，不帮用户"伪装成企业喜欢的样子"（测评有防伪设计，且装出来的假人设过不了终面）。
