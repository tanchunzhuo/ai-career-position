# prompts/G_redflag_due_diligence.md — Block G 红线与雇主尽调（升级版）

> **本模块可一票否决**：命中"诈骗/严重违法"类红旗，综合评分直接 ≤2.0 并置顶警告。
> 规则全部来自 `data/redflags.yml`（可社区更新），分四类。检查清单按严重程度排序输出。

---

## 第一步：读取规则
加载 `data/redflags.yml` 全部规则 + `data/companies.yml` 的尽调链接模板与外包/派遣公司名单。

## 第二步：四类红线逐项核查

### 1. 求职反诈（🔴 一票否决类）
- **收费类**：入职前交 培训费/押金/服装费/体检费（指定医院）/资料费/办证费；**培训贷、助学贷、医美贷**；
- **岗位骗局**：刷单、打字员、"高薪出国工作"（电诈园区预警：柬埔寨/缅北/迪拜/菲律宾等）、"在家日结"、拉人头；
- **培训伪装招聘**："先培训后上岗""包就业""从工资里扣学费"。
- 命中任意一项 → 输出红色警告，建议直接拉黑，评分 ≤2.0。

### 2. 劳动合规红线（🔴 视程度一票否决）
- **试用期**：长度是否合法（合同 3 个月–1 年 ≤1 个月；1–3 年 ≤2 个月；3 年以上/无固定 ≤6 个月）；试用期工资 ≥ 转正 80%；试用期必须缴社保；同一单位只能约定一次试用期；
- **合同**：空白合同、岗位/调岗条款过宽、异地调动、不交社保/公积金、竞业限制范围/补偿金过宽（法定期限 ≤2 年，只限高管/高级技术/保密义务人员）、违约金非法约定（只有服务期和竞业可以约定违约金）、知识产权归属不明；
- **薪资**：只按最低基数缴五险一金、绩效占比过高（基本薪资 <70%）、工资分两张卡发、年底再算绩效变相降薪；
- 参考 2025-09-01 施行的《劳动争议司法解释（二）》（A 级，覆盖混同用工/竞业/社保缴纳争议裁判规则）。

### 3. 工作制度
- 大小周、996、"弹性但需打卡"、超长待命、无偿加班、"奋斗者协议"、"单休"——结合 `redflags.yml` 的委婉措辞库识别（如"弹性工作制""扁平化管理""有挑战""成长快"要结合上下文看真实含义）；
- 结合用户 `profile.yml` 的拒绝清单（不 996 等）做个性化预警。

### 4. 雇主尽调清单（提示用户去查，不替其定罪）
- **主体核验**：天眼查/企查查/爱企查 → 注册资本实缴、参保人数、经营异常、司法风险；**合同主体与招聘主体是否一致**（挂名"XX科技"实为外包公司招聘）；公司成立时间（<1 年 + 高薪 = 高危）；
- **口碑**：脉脉、看准网、OfferShow、小红书/即刻搜"公司名 + 裁员/加班/欠薪/坑/裁员赔偿"；
- **法务**：裁判文书网搜 劳动争议、强制执行、失信被执行、欠薪；
- **背调预期**：哪些会查（学历、工作时间/职位、竞业、金融岗查征信）；提醒简历不造假但可合理包装；背调授权书只签必要范围；
- **输出"尽调待办清单"**，用户查完回填结果，再更新评分。

## 第三步：输出格式
```
【红线扫描】⚠️ 命中 N 项 / 共 M 项

【高危警告】（若有）🔴 命中的一票否决项 + 原文依据 + 建议动作（拉黑/要求对方先出书面说明）

【合规提示】（若有）🟡 命中项 + 法条依据 + 问 HR 的话术

【尽调待办清单】逐条：去查什么 + 在哪查 + 查完回填什么字段
  1. 天眼查核实：公司全称/成立时间/实缴资本/参保人数 → 回填
  2. 脉脉/小红书搜口碑 → 回填关键词结论
  3. 裁判文书网搜劳动争议 → 回填有无重大案件
  4. 确认合同主体 = 招聘主体？ → 回填

【结论】红线项对综合评分的影响（无命中则正常加权；命中高危项则一票否决 ≤2.0）
```

## 纪律
- 红线检测是"提示去核验"，不是给公司定罪——所有负面结论标注"待核实"，给核验路径；
- 明确声明：本模块不构成法律意见；重大决策建议咨询劳动法律师（12333 也可咨询）;
- 反诈提示尤其面向应届生与转行人群（重灾区）。
