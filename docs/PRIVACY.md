# PRIVACY.md — 隐私与合规说明

## 1. 数据边界（硬承诺）

| 数据类型 | 存放位置 | 是否上传 |
|---|---|---|
| 简历（cv.md） | `workspace/` | ❌ 从不 |
| 个人档案（profile.yml） | `workspace/` | ❌ 从不 |
| 薪资/期望/红线 | `workspace/` | ❌ 从不 |
| JD 与投递追踪 | `workspace/` | ❌ 从不 |
| 面试故事与复盘 | `workspace/` | ❌ 从不 |
| 规则与对标数据 | `data/`（随仓库公开） | ✅ 公开（不含个人信息） |

- `workspace/` 已在 `.gitignore` 中，**上传 GitHub 前必查**：
  ```bash
  git status            # 不应出现任何 workspace/ 文件
  git check-ignore workspace/cv.md   # 应输出该路径（说明被忽略）
  ```
- 本仓库不内置任何遥测、统计、第三方请求。唯一的网络出口是**用户主动调用的模型 API**（且经宿主授权）。

## 2. 隐私原则（逐条）

1. **数据最小化**：收集用户的求职所需信息，不收集与求职无关的个人信息；
2. **默认本地**：一切处理优先在本机完成（ATS 解析、简历渲染、JD 存储）；
3. **不登录、不存证**：Inbox 方案不自动登录招聘平台、不存 cookie/密码、不批量爬取；Bookmarklet 只"帮用户复制他本就能看到的文字"；
4. **Inbox 服务只绑定 `127.0.0.1`**，不对外暴露端口；
5. **联网平台慎贴隐私**：使用 Claude/ChatGPT/Kimi 等联网服务时，粘贴完整简历/薪资前请自行判断（建议脱敏：姓名→"本人"、手机号→占位）。WorkBuddy 等本地形态无此顾虑。

## 3. 上传 GitHub 前检查清单

- [ ] `.gitignore` 包含 `workspace/`
- [ ] `git status` 中无任何 `workspace/` 文件
- [ ] `data/*.yml` 中无真实姓名/联系方式/公司内幕信息
- [ ] 示例/占位文件无真实个人信息
- [ ] 若 fork 或二次分发，保留 LICENSE 与致谢

## 4. 合规说明（不构成法律意见）

- 反诈/劳动合规提示：**不构成法律意见**，重大决策请咨询劳动法律师或拨打 12333 人社服务热线；
- 薪资数据标注来源与时点，**不承诺**录用/涨薪结果；
- 简历优化是"真实经历的准确呈现"，本工具**拒绝协助任何形式的简历造假**（学历、经历、证书、年限虚构均属造假，背调风险自负）；
- 遵守各招聘平台 ToS：不做自动登录、不批量爬取、不自动投递。

## 5. 数据删除

- 用户删除 `workspace/` 目录即完成全部个人数据删除（数据不进入任何云端）；
- 若曾把隐私内容粘贴给联网 AI 平台，需到该平台单独清理对话记录（本工具无法代为处理）。
